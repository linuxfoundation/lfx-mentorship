A program page is where you decide whether a program is a fit. It carries the term dates, the stipend, the skills, and the people already involved.

## Before you begin

No sign-in is required to read a program page.

## Steps

1. Open any program from [Find a Program](../browsing-programs/).

    ![Program page](/images/docs/screenshots/programs/program-detail.png)

2. Read the header. It carries the project logo and name, the program's status badge, and the skills the program lists.
3. Check the sidebar for the facts that decide whether you can take part:

    | Field | What it tells you |
    |---|---|
    | **Term** | Which term this page is for |
    | **Applications close** | The last day to apply |
    | **Stipend** | The amount, or that the amount is determined by mentee location |

4. Work through the tabs:
   - **Overview** — the program description and what the project expects from a mentee.
   - **Terms** — the dates for this and any earlier terms.
   - **Mentors** — who will review your work.
   - **Mentees** — who has taken part in this program before.
   - **Sponsors** — who funds the program, where it is funded.

    ![Program mentors tab](/images/docs/screenshots/programs/program-detail-mentors.png)

5. Use the header actions:
   - **Apply to This Program** — opens the application in LFX.
   - **Repository** — the project's source repository.
   - **Donate** — fund the program through LFX Crowdfunding.
   - **Code of Conduct** — the project's code of conduct.

## After completing

**Apply to This Program** takes you to [app.lfx.dev](https://app.lfx.dev), where the application itself lives. See [Apply to a Program](../../mentees/apply-to-a-program/).
