A mentor profile is what Program Admins and applicants see. It has to exist before you can join a program.

## Before you begin

- You need an [LF ID](https://openprofile.dev/).
- Have your introduction, skills and project links ready — the same things a mentee reads before applying.

## Steps

1. Select **Become a Mentor** in the top navigation, or go to [app.lfx.dev/mentorship/mentor](https://app.lfx.dev/mentorship/mentor).
2. Sign in with your LF ID.
3. Fill in the mentor registration form and save it.
4. To join a program, open **My Programs** in LFX and request the program you want to mentor.

## After completing

The Program Admin approves or declines your request. You can withdraw a request while it is still open. Once you are on a program, its mentees and tasks appear under **My Programs**.

If you already had a mentor profile, opening the same link takes you straight to **My Programs** rather than the form.
