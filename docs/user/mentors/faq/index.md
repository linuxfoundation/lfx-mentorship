## How do I get onto a program?

Either a Program Admin invites you by email, or you request the program from **My Programs** in LFX and the Program Admin approves it.

## I was invited but the link does not work.

Invitation links are one-time. Ask the Program Admin to send a fresh invitation.

## Can I withdraw a request to mentor?

Yes, while the request is still open. Open **My Programs** in LFX and withdraw it.

## Can I mentor more than one program?

Yes. Every program you mentor appears under **My Programs**.

## Where do I review what a mentee submitted?

Open the program from **My Programs** in LFX, then the mentee's tasks. You review each submitted task there.

## How do I record something about a mentee?

Leave a note on the mentee from the program's mentee list in LFX. Notes are for the program's mentors and Program Admins, not for the mentee.

## Why does the site say "Program Admin" and not "maintainer"?

"Maintainer" means an upstream project maintainer elsewhere in LFX. The person who administers a mentorship program is a **Program Admin**.
