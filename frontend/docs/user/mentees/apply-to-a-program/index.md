Applying happens in LFX, the Linux Foundation's software platform. This site is where you find the program; the application itself is at [app.lfx.dev](https://app.lfx.dev).

## Before you begin

- You need a mentee profile. See [Become a Mentee](../become-a-mentee/).
- You may have at most **three** open applications at a time. Withdrawing one frees a slot.
- Check the program's prerequisites on its page first — several ask for a resume, a cover letter on set topics, a coding challenge, or school enrollment verification.
- Check **Applications close** in the program sidebar.

## Steps

1. Open the program you want from [Find a Program](../../programs/browsing-programs/).
2. Select **Apply to This Program**. You are taken to LFX and asked to sign in.
3. Confirm you meet the program's eligibility checks.
4. Complete each prerequisite the program requires.
5. Acknowledge the program terms and the compliance confirmation.
6. Submit the application.

## After completing

Your application appears in your mentee overview at [app.lfx.dev/mentorship/mentee](https://app.lfx.dev/mentorship/mentee), and the program's mentors review it against the skills the program listed and what you wrote.

| Outcome      | What it means                                          |
| ------------ | ------------------------------------------------------ |
| **Pending**  | Submitted and waiting for the Program Admins' decision |
| **Accepted** | You have a place on the term; your tasks appear in LFX |
| **Declined** | The program did not take you on for this term          |

A turned-down application is always **declined**. You can apply to a different program, or to the same program in a later term.
