Program admins run a mentorship program. You enroll it, set its terms and prerequisites, invite mentors, and decide which mentees are accepted. You work in the [Admin](https://app.lfx.dev/mentorship/admin) area of LFX Self Serve.

## Enroll a program

Select **Enroll a Program** on the Mentorship site or in the Admin area. The form has these steps:

1. **Program Details**: the program name, the Linux Foundation open source project it belongs to, technologies, description, repository and website URLs, Code of Conduct URL, and the logo shown on your program page. Select **Import from existing program** to copy details, skills and prerequisites from a program you ran before, or start from a template.
2. **Program Setup**: the required or desirable skills, and the program terms. For each term, set the name, start and end month and year, and the application start and end dates.
3. **Prerequisites**: choose the standard prerequisites and add your own with **Add Custom Prerequisite**, each with a name, description, due date and optional URL.

When you submit, the Linux Foundation reviews the program. You get an email when it is approved or rejected. Approved programs appear on the Mentorship site.

## Manage your program

Open the program from the Admin area. **Edit Program** changes its details, and **View Public Page** opens it on the Mentorship site. The program has four tabs:

- **Current Mentees**: applications and accepted mentees for open terms.
- **Past Mentees**: mentees from earlier terms.
- **Mentors**: your program's mentors and pending invitations.
- **Terms**: create and manage terms.

## Review and accept mentees

In **Current Mentees**, filter by term or status and open an applicant to see their prerequisite tasks and other active applications. Then:

- **Accept**: choose the attendance type, **Full time** or **Part time**, and confirm. The mentee gets an email, and the Linux Foundation's HR team starts onboarding.
- **Decline**: declines one application. The applicant gets an email.
- **Decline by Term**: declines every pending application in a term at once, for example after you have accepted your mentees.
- **Graduate**: marks a mentee who completed the program as graduated.

You can add notes to an application, and **Download By Status** exports the list.

## Invite and manage mentors

In **Mentors**, search for a person and select **Invite**. They get an email to accept or decline. Select **Revoke invite** to cancel an invitation that has not been answered. Mentors who request to join your program also appear here for you to approve or decline.

## Manage terms

In **Terms**, select **Create Term** to add a term. Applications open and close on the term's application dates. You can also close, re-open or delete a term.
