## How do I get onto a program?

Either a Program Admin invites you by email, or you request the program from **My Programs** in LFX, the Linux Foundation's software platform, and the Program Admin approves it.

## Why doesn't my invitation link work?

Invitation links can only be used once. Ask the Program Admin to send a fresh invitation.

## Can I withdraw a request to mentor?

Yes, you can withdraw a request while it is still open. Open **My Programs** in LFX and withdraw it.

## Can I mentor more than one program?

Yes, you can mentor as many programs as you are accepted onto. Every program you mentor appears under **My Programs**.

## Where do I review what a mentee submitted?

Open the program from **My Programs** in LFX, then the mentee's tasks. You review each submitted task there.

## How do I record something about a mentee?

Leave a note on the mentee from the program's mentee list in LFX. Notes are for the program's mentors and Program Admins, not for the mentee.
