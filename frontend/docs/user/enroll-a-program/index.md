Program Admins enroll a program for a Linux Foundation project and bring on paid, mentored contributors for a multi-week term. LFX, the Linux Foundation's software platform, runs applications, stipends, evaluations and compliance; the project scopes the work and reviews it.

![Enroll a Program](/images/docs/screenshots/enroll-a-program/enroll-landing.png)

## Before you begin

- You must be signed in to LFX as a **Program Admin** for the project.
- Scope the work for a single term.
- Confirm funding before enrolling.

## What the form asks for

Enrollment is a three-step form in the LFX Admin area. Gather these before you start: nothing is saved until you submit the last step, so plan to finish it in one sitting.

| Step                   | What it asks for                                                                                                                                                                                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Program Details** | Program name, program description, Code of Conduct URL, the Linux Foundation project, repository and website URLs, program logo, technologies, CII (Core Infrastructure Initiative) Best Practices project ID. You can import details from a program you have run before. |
| **2. Program Setup**   | Required and desirable skills, custom term dates, non-technical interest areas, program terms. Mentors are invited later, once the program is approved.                                                                                                                   |
| **3. Prerequisites**   | What candidates must complete to qualify: resume, participation permission, terms and conditions, cover letter topics, coding challenge, school enrollment verification, and any custom prerequisites. Plus the platform terms.                                           |

## Steps

1. Select **Enroll a Program** from the top navigation. This opens the Admin area of LFX at [app.lfx.dev/mentorship/admin](https://app.lfx.dev/mentorship/admin).
2. Sign in as a Program Admin.
3. Complete **Program Details**, **Program Setup** and **Prerequisites**.
4. Submit the enrollment.

## After you submit

1. The LFX Mentorship team reviews your enrollment. It can take up to 5 business days, but most reviews are completed within 24 hours. A program that is not approved is **rejected**.
2. Once approved, invite mentors from the **Mentors** tab.
3. The program opens for applications, and applicants appear in your workspace.

## Why offer a program

- **Grow your contributor base** — most graduated mentees keep contributing after the term, often becoming reviewers and core contributors.
- **Move work you keep deferring** — tooling, tests, docs and instrumentation suit a scoped term well.
- **Funding you control** — where a program is funded, the stipend comes from project funds, a foundation pool or a direct sponsor.
- **Program administration handled** — LFX runs applications, eligibility checks, stipend payments, evaluations and compliance.
- **A wider pool of candidates** — your program is listed alongside every other LFX program.
- **A record you can point to** — every term keeps its mentees, approved work and outcomes.
