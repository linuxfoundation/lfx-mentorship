A **program** is one project's mentorship offering. Every program belongs to a Linux Foundation project, lists the skills it is looking for, and runs in dated **terms**.

## What you can do

- Browse every program across all participating foundations
- Filter by status and by skill, and search by name
- Open a program to read its description, term dates, stipend, mentors, mentees and sponsors
- Start an application from the program page

## Program status

| Status          | What it means                                              |
| --------------- | ---------------------------------------------------------- |
| **Accepting**   | The term is open and taking applications                   |
| **Opens soon**  | The term is announced but applications have not opened yet |
| **In progress** | The term is under way; applications are closed             |
| **Completed**   | The term has finished                                      |

Only approved programs appear on this site. A program that was not approved during moderation is **rejected** and is never listed.
