Find a Program lists every program across all participating foundations, including terms already under way.

## Before you begin

No sign-in is required to browse programs. To apply to one you will need an [LF ID](https://openprofile.dev/) account.

## Steps

1. Select **Find a Program** from the top navigation.

   ![Find a Program](/images/docs/screenshots/programs/programs-browse.png)

2. Each card shows the project logo, the term, the program name, a short description, the skills the program lists, and how many mentors it has.
3. Narrow the list:
   - **Search** — type part of a program or project name.
   - **Status pills** — **All**, **Accepting**, **In progress** or **Completed**.
   - **All skills** — pick a skill to show only programs that list it.
   - **Accepting First** — change the sort order.
4. Select **View program** on any card to open the program page.

## After completing

The program page opens, with its term dates, stipend, mentors and mentees. See [Program Pages](../program-pages/).
